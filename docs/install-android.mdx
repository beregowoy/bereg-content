# Установка на Android

Инструкция подходит для Android 8 и выше.

## Шаг 1. Установите приложение

Основной клиент для Android — **Happ**.

- [Установить Happ из Google Play](https://play.google.com/store/apps/details?id=com.happproxy) — бесплатно.

Само приложение доступа в интернет не даёт: в него добавляется ссылка подписки
с нашими серверами, и дальше оно подключается через них.

## Шаг 2. Добавьте подписку

1. Откройте [личный кабинет](https://app.beregvpn.com).
2. Перейдите в раздел **Подключить VPN**.
3. Выберите платформу **Android** и нажмите **Импорт** — подписка добавится в Happ автоматически.

<Callout type="info" title="Если приложение не открылось">
  В разделе **Подключить VPN** откройте пункт **Альтернативная инструкция**,
  скопируйте на этой странице ссылку подписки, откройте Happ вручную и вставьте
  ссылку в поле добавления подписки — **Add subscription** («Добавить подписку»)
  или **Import from clipboard** («Импорт из буфера обмена»). На той же странице
  собраны ссылки на приложения, если Google Play недоступен.
</Callout>

## Шаг 3. Подключитесь

1. Выберите нужный сервер в списке.
2. Нажмите кнопку подключения внизу экрана.
3. Android спросит разрешение на создание VPN-соединения — нажмите **OK**.

В шторке уведомлений появится значок **Ключ** — VPN активен.

<Callout type="tip" title="Совет">
  Разрешите приложению работать в фоне и отключите экономию батареи
  для клиента VPN, иначе Android может обрывать соединение.
</Callout>

## Частые проблемы

- **Нет интернета после подключения.** Попробуйте другой сервер.
- **Соединение обрывается.** Снимите ограничения экономии батареи.
- **Ошибка импорта подписки.** Скопируйте ссылку заново из кабинета.

Если не получается подключиться — напишите в [поддержку](https://t.me/beregvpn_supportbot).
