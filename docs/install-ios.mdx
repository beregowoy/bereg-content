# Установка на iOS

Инструкция подходит для iPhone и iPad с iOS 15 и выше.

## Шаг 1. Установите приложение

Основной клиент для iPhone и iPad — **INCY**.

- [Установить INCY из App Store](https://apps.apple.com/ru/app/incy/id6756943388) — бесплатно.

Само приложение доступа в интернет не даёт: в него добавляется ссылка подписки
с нашими серверами, и дальше оно подключается через них.

## Шаг 2. Добавьте подписку

1. Откройте [личный кабинет](https://app.beregvpn.com).
2. Перейдите в раздел **Подключить VPN**.
3. Выберите платформу **iOS** и нажмите **Импорт** — подписка добавится в INCY автоматически.

<Callout type="info" title="Если приложение не открылось">
  В разделе **Подключить VPN** откройте пункт **Альтернативная инструкция**,
  скопируйте на этой странице ссылку подписки, откройте INCY вручную и вставьте
  ссылку в поле добавления подписки — **Add Subscription** («Добавить подписку»)
  или **Import from URL** («Импорт по ссылке»).
</Callout>

## Шаг 3. Разрешите VPN

При первом подключении iOS покажет запрос **«Разрешить добавить конфигурации VPN»** —
нажмите **Разрешить** и подтвердите действие через Face ID / Touch ID или код-пароль.

## Шаг 4. Подключитесь

Выберите сервер в списке и нажмите большую кнопку подключения. В статус-баре
появится значок **VPN** — всё работает.

## Частые проблемы

- **Приложение не видит серверы.** Перезапустите приложение и обновите
  подписку в нём (**Update subscription** / «Обновить»).
- **Медленно работает.** Попробуйте другой сервер из списка.

Если проблема осталась — напишите в [поддержку](https://t.me/beregvpn_supportbot).
