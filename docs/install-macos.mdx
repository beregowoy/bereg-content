# Установка на macOS

Инструкция подходит для macOS 12 Monterey и новее, работает на Intel и Apple Silicon.

## Шаг 1. Установите клиент

Основной клиент для Mac — **Koala Clash**.

- [Установить Koala Clash из App Store](https://apps.apple.com/app/id6746188973) — бесплатно.

## Шаг 2. Добавьте подписку

1. Откройте [личный кабинет](https://app.beregvpn.com).
2. Перейдите в раздел **Подключить VPN**.
3. Выберите платформу **macOS** и нажмите **Импорт** — подписка добавится в Koala Clash автоматически.

<Callout type="info" title="Если приложение не открылось">
  В разделе **Подключить VPN** откройте пункт **Альтернативная инструкция**,
  скопируйте на этой странице ссылку подписки, откройте клиент вручную и вставьте
  ссылку в раздел подписок — **Add subscription** («Добавить подписку»), затем
  нажмите **Update** («Обновить»), чтобы загрузить список серверов.
</Callout>

## Шаг 3. Подключитесь

1. Выберите сервер.
2. Нажмите большую кнопку **Connect**.
3. macOS спросит разрешение на добавление VPN-конфигурации — введите пароль администратора.

В строке меню появится иконка VPN — соединение работает.

<Callout type="info" title="Если кнопка не активна">
  Перейдите в **Системные настройки → VPN** и проверьте, что добавленный
  профиль не заблокирован. Иногда macOS требует разрешить расширение в
  **Конфиденциальность и безопасность**.
</Callout>

## Частые проблемы

- **Не видно подписки.** Нажмите **Update subscription** в настройках клиента.
- **Нет интернета.** Переключите режим на **TUN/Global** в настройках.
- **Приложение не запускается.** ПКМ по иконке → **Открыть** в первый раз.
